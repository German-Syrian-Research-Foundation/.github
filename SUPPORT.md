# Support

Where to go, depending on what you need.

## I am a student, applicant, or researcher

GitHub is not the right place — we cannot see applications or member records here.

| Your question | Where to go |
|:--|:--|
| Scholarships, programmes, eligibility | [ds-fg.com/scholarships](https://ds-fg.com/scholarships/) |
| Mentoring (Maabar) | [ds-fg.com/service/mentoring](https://ds-fg.com/service/mentoring/) |
| Membership and applications | [ds-fg.com/membership-application](https://ds-fg.com/membership-application/) |
| Community and peer support | [community.ds-fg.com](https://community.ds-fg.com/login) |
| Anything else | [info@ds-fg.com](mailto:info@ds-fg.com) |

**Please do not post personal details, CVs, or application documents in a GitHub issue.** Issues are public and permanent.

## I found a problem in a repository

1. Check the repository's own `README.md` first.
2. Search [open and closed issues](https://github.com/search?q=org%3AGerman-Syrian-Research-Foundation&type=issues) — it may already be known.
3. Open a new issue on the relevant repository using the appropriate template.

## I want to use or reuse DSFG material

- **Code and documents** — see the `LICENSE` file in the repository.
- **Logos, name, and brand marks** — see [brand usage](https://github.com/German-Syrian-Research-Foundation/assets/blob/main/BRAND-USAGE.md). Partner and press use is generally welcome; you need written permission for anything implying endorsement.

## I found a security vulnerability

Do **not** open an issue. Follow the [security policy](SECURITY.md).

## I want to report a code of conduct violation

Email [info@ds-fg.com](mailto:info@ds-fg.com) — not the technical inbox. See the [Code of Conduct](CODE_OF_CONDUCT.md).

## Response times

DSFG is run largely by volunteers. Expect a reply within **5–10 working days**, longer during the summer and around major holidays. Security reports are prioritised.
